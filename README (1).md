## **Project: Personal Portfolio Website**

This project is a basic personal portfolio website created using HTML, CSS, and JavaScript as part of the Git and GitHub practical assignment.

## **Technologies Used**

- **HTML:** Used to create the structure of the webpage.
- **CSS:** Used for styling, colors, layout, and responsive design.
- **JavaScript:** Used to add interactive features to the website.

## **Portfolio Sections**

1. **Home:** Introduction and welcome section.
2. **About Me:** Personal introduction and background.
3. **Skills:** Technical skills including HTML, CSS, JavaScript, Python, C++, and Java.
4. **Projects:** Displays my academic and programming projects.
5. **Contact:** Provides email information for communication.

## **Project Files**

- index.html – Website structure.
- style.css – Website design and styling.
- script.js – Website functionality.
- README.md – Project documentation.

## **How to Run the Project**

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html.
4. Run the webpage using Live Server.
5. View the portfolio in your web browser.
