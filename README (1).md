## Project: Personal Portfolio Website

This repository contains my basic personal portfolio webpage, created as
part of the Git and GitHub practical task.

### Technologies Used

-   **HTML (`index.html`)** -- Provides the structure and content of the
    webpage.
-   **CSS (`style.css`)** -- Controls the styling, layout, colors, and
    responsive design.
-   **JavaScript (`script.js`)** -- Adds simple interaction, including
    the mobile navigation menu and automatic copyright year.

### Portfolio Sections

-   **Home** -- Introduction and welcome section.
-   **About Me** -- A short personal introduction.
-   **Skills** -- Technical skills.
-   **Projects** -- A showcase of projects.
-   **Contact** -- Contact information and an email link.

### Project Files

``` text
.
├── index.html
├── style.css
├── script.js
└── README.md
```

### How to Run the Project

1.  Clone or download this repository.
2.  Open the project folder in Visual Studio Code.
3.  Open `index.html` in a browser, or use the Live Server extension in
    VS Code.
4.  The HTML file loads `style.css` for styling and `script.js` for
    JavaScript functionality.

### Git and GitHub Practical Work

This project is maintained using Git and GitHub. The practical work
includes:

-   Creating a GitHub repository.
-   Adding and pushing the portfolio project files.
-   Making at least three meaningful commits.
-   Creating and pushing the `feature-navbar` branch for the navigation
    bar.
-   Creating and pushing the `feature-footer` branch for the footer.
-   Merging both feature branches into `main`.
